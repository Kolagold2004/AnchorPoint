# Contract Registry Events

| Topic | Data | Emitted when |
| --- | --- | --- |
| `reg_init` | `admin` | The registry is initialized. |
| Registration/update events | Contract type and address values | A contract is registered or its address changes. |
| `deactiv`, `activate` | Contract type and active state | A contract type is disabled or enabled. |
| `remove` | Contract type and removal state | A contract registration is removed. |
| Admin proposal, transfer, pause, and unpause events | Admin and resulting state | Registry governance or pause state changes. |
